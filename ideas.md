- Predictive math canvas — AI-native STEM notebook for iPad. Two core interactions: (1) cleans up messy handwriting into legible math notation, (2) predicts and completes partial graphs/equations as you sketch them (ghost layer, like Copilot). Concept tracking layer logs which ideas you consistently struggle with across sessions. Gap confirmed: MathNotes has the AI sidebar but no graph completion or personal pattern learning. AmIWrite (CHI 2026) has annotation-on-handwriting but isn't a consumer app. Full vision: PencilKit canvas + Claude Vision API + ghost layer completion. Validation path: try MathNotes first (30 min), then browser prototype if gap confirmed.
- Clay for new businesses (domain scraper + LLM classifier): Scrape all newly registered domains daily (public data), send each through an LLM to validate whether it is a real new business and classify it (jet ski rental, law firm, contractor, etc.) with structured fields (location, size, vertical). Clay does not serve this segment well because it is an aggregator of existing data, not new registrations. Initial validation: ~15 confirmed new jet ski rental businesses found. Construction is the next test vertical (high AP invoice volume = strong Ramp fit). Distribution angle: sell curated daily lead lists to vertical-specific sellers (insurance, fintech, ERP, etc.) who want to be first to a new business before any competitor knows it exists.
- Retail tech layer for CPG brokerages: Small CPG brands cannot build the data and analytics infrastructure that retail brokers need to make shelf-placement arguments to Target, Walmart, etc. Bluebird Group (and firms like it) used data to displace beef jerky with Chomps at Target. The broker industry's next 10 years will be tech-driven but small brands are not building it themselves. A platform that sits between the small brand and the broker -- handling the analytics, category data, and shelf argument -- could become the operating system for indie CPG retail distribution.
